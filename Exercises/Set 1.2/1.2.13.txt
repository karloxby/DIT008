1.2.13.		Let A = {1, 2, 3}, B = {u}, and C = {m, n}. Find
		each of the following sets.

		a. A × (B × C)
		b. (A × B) × C
		c. A × B × C


		a. A × (B × C)
		
		A = {1, 2, 3}
		B = {u}
		C = {m, n}

		B × C = {(u, m), (u, n)}

		A × (B × C) = {
				(1, (u, m)), (1, (u, n)),
				(2, (u, m)), (2, (u, n)),
				(3, (u, m)), (3, (u, n))
			}

Solution:	A × (B × C) = {
				(1, (u, m)), (1, (u, n)), 
				(2, (u, m)), (2, (u, n)), 
				(3, (u, m)), (3, (u, n))
			}


		b. (A × B) × C

		A = {1, 2, 3}
		B = {u}
		C = {m, n}

		A × B = {(1, u), (2, u), (3, u)}

		(A × B) × C = {
				((1, u), m), ((2, u), m), ((3, u), m),
				((1, u), n), ((2, u), n), ((3, u), n)
			}

Solution:	(A × B) × C = {
				((1, u), m), ((2, u), m), ((3, u), m),
				((1, u), n), ((2, u), n), ((3, u), n)
			}


		c. A × B × C

		A = {1, 2, 3}
		B = {u}
		C = {m, n}

		A × B × C = {
				(1, u, m), (1, u, n),
				(2, u, m), (2, u, n),
				(3, u, m), (3, u, n)
			}

Solution:	A × B × C = {
				(1, u, m), (1, u, n),
				(2, u, m), (2, u, n),
				(3, u, m), (3, u, n)
			}
