1.2.12.		Let S = {2, 4, 6} and T = {1, 3, 5}. Use the set-
		roster notation to write each of the following sets, and
		indicate the number of elements that are in each set.

		a. S × T
		b. T × S
		c. S × S
		d. T × T


		a. S × T

		S = {2, 4, 6}
		T = {1, 3, 5}

		S × T = {
			(2, 1), (2, 3), (2, 5),
			(4, 1), (4, 3), (4, 5),
			(6, 1), (6, 3), (6, 5),
			}

Solution:	There are nine elements in the resulting set.


		b. T × S

		T = {1, 3, 5}
		S = {2, 4, 6}

		T × S = {
			(1, 2), (1, 4), (1, 6),
			(3, 2), (3, 4), (3, 6),
			(5, 2), (5, 4), (5, 6)
			}

Solution:	There are nine elements in the resulting set.


		c. S × S

		S = {2, 4, 6}

		S × S = {
			(2, 2), (2, 4), (2, 6),
			(4, 2), (4, 4), (4, 6),
			(6, 2), (6, 4), (6, 6)
			}

Solution:	There are nine elements in the resulting set.


		d. T × T

		T = {1, 3, 5}

		T × T = {
			(1, 1), (1, 3), (1, 5),
			(3, 1), (3, 3), (3, 5),
			(5, 1), (5, 3), (5, 5)
			}

Solution:	There are nine elements in the resulting set.
