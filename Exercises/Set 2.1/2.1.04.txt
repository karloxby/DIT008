		a.	If the program syntax is faulty, then the
			computer will generate an error message.

			If the computer generates an error message,
			then the program will not run.

			Therefore, if the program syntax is faulty, then
			the program will not run.

			
			Let p =		The program syntax is faulty
			Let q =		The computer will generate an error 
					message.

			Let r =		The program will not run


Solution:		p → q
			q → r
			∴ p → r
