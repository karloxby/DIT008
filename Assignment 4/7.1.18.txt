7.1.18.		Find exact values for each of the following quantities
		without using a calculator.

		a.	log₃ 81
		b.	log₂ 1024
		c.	log₃ (1/27)
		d.	log₂ 1
		e.	log₁₀ (1/10)
		f.	log₃ 3
		g.	log₂ (2ᵏ)


a.	log₃ 81
	
		Definition of Logarithms and Logarithmic Functions:
		
			logₐ x = y ↔ aʸ = x

		log₃ 81 = y
		3ʸ = 81
		
			3¹ = 3
			3² = 3 * 3 = 9
			3³ = 9 * 3 = 27
			3⁴ = 27 * 3 = 81

		Hence, log₃ 81 = 4

Solution:	log₃ 81 = 4


b.	log₂ 1024
	
		Definition of Logarithms and Logarithmic Functions:
		
			logₐ x = y ↔ aʸ = x

		log₂ 1024 = y
		2ʸ = 1024

			2¹ = 2
			2² = 4
			2³ = 8
			2⁴ = 16
			2⁵ = 32
			2⁶ = 64
			2⁷ = 128
			2⁸ = 256
			2⁹ = 512
			2¹⁰ = 1024

		Hence, log₂ 1024 = 10

Solution:	log₂ 1024 = 10


c.	log₃ (1/27)
	
		Definition of Logarithms and Logarithmic Functions:
		
			logₐ x = y ↔ aʸ = x

		log₃ (1/27) = y
		3ʸ = 1 / 27

			3³ = 27

			1 / 27 = 1 / 3³ = 3⁻³

		Hence, log₃ (1/27) = -3

Solution:	log₃ (1/27) = -3


d.	log₂ 1
	
		Definition of Logarithms and Logarithmic Functions:
		
			logₐ x = y ↔ aʸ = x

		log₂ 1 = y
		2ʸ = 1

			2⁰ = 1

		Hence, log₂ 1 = 0

Solution:	log₂ 1 = 0


e.	log₁₀ (1/10)
	
		Definition of Logarithms and Logarithmic Functions:
		
			logₐ x = y ↔ aʸ = x

		log₁₀ (1/10) = y
		10ʸ = 1 / 10

			1 / 10 = 10⁻¹

		Hence, log₁₀ (1/10) = -1

Solution:	log₁₀ (1/10) = -1


f.	log₃ 3
	
		Definition of Logarithms and Logarithmic Functions:
		
			logₐ x = y ↔ aʸ = x

		log₃ 3 = y
		3ʸ = 3

			3¹ = 3

		Hence, log₃ 3 = 1

Solution:	log₃ 3 = 1


g.	log₂ (2ᵏ)
	
		Definition of Logarithms and Logarithmic Functions:
		
			logₐ x = y ↔ aʸ = x

		log₂ (2ᵏ) = y
		2ʸ = 2ᵏ

		Hence, log₂ (2ᵏ) = k

Solution:	log₂ (2ᵏ) = k
