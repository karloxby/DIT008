j = i - 1.


5.1.57.		ⁿ⁻¹∑ᵢ₌₁ i / (n - i)²

		
		We must transform the expression by change
		of variable j = i - 1

			j = i - 1
			i = j + 1

			ⁿ⁻¹∑ᵢ₌₁ i / (n - i)² =
			ⁿ⁻¹∑ᵢ₌₁ (j + 1) / (n - (j + 1))² =
			ⁿ⁻¹∑ᵢ₌₁ (j + 1) / (n - j - 1)²

		Now we must also change the lower- and upper
		bounds.

			i = j + 1

			j + 1 = 1
			j = 0
			
			j + 1 = n - 1
			j = n - 2
		

Solution:	ⁿ⁻²∑ⱼ₌₀ (j + 1) / (n - j - 1)²
