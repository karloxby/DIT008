5.1.70.		n! / (n - k + 1)!


		What is n factorial?

			n! = n(n - 1)(n - 2) ... 3 * 2 * 1

		Therefore:

			(n - k + 1)! = (n - k + 1)(n - k)(n - k - 1) ... 3 * 2 * 1

		So, how can we express n! as (n - k + 1)!?

			n! = n(n - 1)(n - 2) ... (n - k + 1) ... 3 * 2 * 1
			n! = n(n - 1) ... (n - k + 1)!
			n! = n(n - 1) ... (n - k + 2)(n - k + 1)!
			
			(n(n - 1) ... (n - k + 2)(n - k + 1)!) / (n - k + 1)!


Solution:	n(n - 1) ... (n - k + 2)
