5.2.17.		ⁿ∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2))) = 1 / (2n + 2)!
		for every integer n ≥ 0.


		Proof:

		P(n) : ⁿ∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2))) = 1 / (2n + 2)!

		Basic step: P(0)

			LHS:
				
				⁰∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2))) =
				(1 / (2(0) + 1)) * (1 / (2(0) + 2)) = 1 / 1 * 1 / 2 = 1 / 2

			RHS:

				1 / (2n + 2)! = 1 / (2(0) + 2)! = 1 / 2!
				1 / 2! = 1 / (2 * 1) = 1 / 2

			Therefore, P(0) is true.

		Inductive step: P(k + 1)

			P(k) : ᵏ∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2))) = 1 / (2k + 2)!

			Suppose P(k) is true. We must show inductively that if
			P(k) is true, then P(k + 1) is true.

			LHS:

				ᵏ∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2)))

					(1/1 * 1/2) * (1/3 * 1/4) * ... * ((1 / (2k + 1)) * (1 / (2k + 2))) =
					1 / (1 * 2 * 3 * 4 * ... * (2k + 1) * (2k + 2)) = 1 / (2k + 2)!

			RHS:

				1 / (2n + 2)! = 1 / (2k + 2)!

			Therefore P(k) is true.

			Now we can show that P(k + 1) is true.

			P(k + 1) : ᵏ⁺¹∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2))) = 1 / (2(k + 1) + 2)!

			LHS:
			
				ᵏ⁺¹∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2)))

					(1/1 * 1/2) * (1/3 * 1/4) * ... * ((1 / (2k + 1)) * (1 / (2k + 2))) * ((1 / (2(k + 1) + 1)) * (1 / (2(k + 1) + 2))) =
					= ᵏ∏ᵢ₌₀ ((1 /(2i + 1)) * (1 / (2i + 2)))* ((1 / (2(k + 1) + 1)) * (1 /(2(k + 1) + 2))) =
					1 / (1 * 2 * 3 * 4* ... * (2(k + 1) + 1) * (2(k + 1) + 2)) = 1 / (2(k + 1) + 2)!

			RHS:

				1 / (2n + 2)! = 1 / (2(k + 1) + 2)!
			
			Therefore, P(k + 1) is true.

									□


Solution:	ⁿ∏ᵢ₌₀ ((1 / (2i + 1)) * (1 / (2i + 2))) = 1 / (2n + 2)!
		for every integer n ≥ 0.
