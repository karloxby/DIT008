4.6.7.		If k is an integer, what is ⌈k + (1 / 2)⌉? Why?

		
		Suppose k is an integer.

		We must show the ceiling of k + (1 / 2) and
		explain.

		Given any real number x, the ceiling of defined as
		follows:

		"⌈x⌉ = n ↔ n - 1 < x ≤ n"

		Let x = k + (1 / 2), for some k ∈ ℤ

		Let's start by finding a pattern:

			k = -1
			x = -1 + (1 / 2) = -0.5
			⌈x⌉ = ⌈-0.5⌉ = 0

			k = 0
			x = 0 + (1 / 2) = 0.5
			⌈x⌉ = ⌈0.5⌉ = 1
		
			k = 1
			x = 1 + (1 / 2) = 1.5
			⌈x⌉ = ⌈1.5⌉ = 2

		x = k + (1 / 2)
		⌈x⌉ = ⌈k + (1 / 2)⌉ = k + 1

		Let n = k + 1, for some k ∈ ℤ

		⌈x⌉ = n ↔ n - 1 < x ≤ n

		⌈k + (1 / 2)⌉ = (k + 1) ↔ (k + 1) - 1 < (k + (1 / 2)) ≤ (k + 1)
		= k + 1 ↔ k < (k + (1 / 2) ≤ k + 1

Solution:	The ceiling of k + (1 / 2) is k + 1, because k < k + (1 / 2) ≤ k + 1,
		by definition of ceiling, ⌈k + (1 / 2)⌉ = k + 1.
