Prove statements 15 and 16 directly
from the definition of divisibility.

4.4.16.		For all integers a, b, and c, if a|b and a|c then
		a|(b + c)


		Suppose a, b, and c are integers.

		We must show that if b is divisible by a, and c
		is divisible by a, then the sum of b and c is
		divisible by a.

		∀a, b, c ∈ Z, a|b ∧ a|c → a|(b + c)

		The definition of divisibility according to Epp:

		"n is divisible by d ↔ n = d * k, for some integer
		k, and d ≠ 0"

		Let a, b, c ∈ Z

			a|b ↔ b = ak, for some k ∈ Z
			a|c ↔ c = aj, for some j ∈ Z

			a ≠ 0

			(b + c) = (ak + aj) = a(k + j)

			a(k + j) / a = k + j

			(k + j) ∈ Z

Solution:	Therefore, if a|b and a|c, then a|(b + c)
