Prove each of the satements in 23-33.


4.6.33.		A necessary and sufficient condition for an integer
		n to be divisible by a nonzero integer d is that
		n = ⌊n/d⌋d. In other words, for every integer n
		and nonzero integer d,

		a. if d|n, then n = ⌊n/d⌋d.
		b. if ⌊n/d⌋d then d|n.


		a.	If d|n, then n = ⌊n/d⌋d

		Proof:

			Suppose n and d are any integers, and d ≠ 0.

			We must show that if d|n, then n = ⌊n/d⌋d.

			Let's assume that the given statement is
			true.

			And the definition of divisibility is:

				d|n ↔ ∃k ∈ ℤ such that n = dk

			So let some k ∈ ℤ, and n = dk, ∀n ∈ ℤ

				d|dk = dk / d = k

			Next we look at the definition of floor:

				⌊x⌋ = n ↔ n ∈ ℤ and n ≤ x < n + 1

			And since we know that d|dk = k, and k ∈ ℤ,
			therefore ⌊k⌋ = k

			And ⌊k⌋d = kd = dk, which is what was to be
			shown.

								□

Solution:	If d|n, then n = ⌊n/d⌋d
		

		b.	If ⌊n / d⌋d, then d|n

		Proof:

			Suppose n and d are any integers, and d ≠ 0.

			We must show that if ⌊n / d⌋d, then d|n.

			Let's assume that the given statement is
			true.

			Let n ∈ ℤ
			Let d ∈ ℤ

			The definition of floor is:

				⌊x⌋ = n ↔ n ∈ ℤ and n ≤ x < n + 1

			Since we know both n and d are some
			integers, ⌊n / d⌋ is also an integer.

			Let ⌊n / d⌋ be some k ∈ ℤ

			⌊n / d⌋d = kd = dk	
			
			The definition of divisiblity is:

				d|n ↔ ∃k ∈ ℤ such that n = dk

			n = ⌊n / d⌋d = dk, which is what was to
			be shown.

								□

Solution:	If ⌊n / d⌋d, then d|n
