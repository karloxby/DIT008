4.5.17.		Prove directly from the definitions that for every
		integer n, n² - n + 3 is odd. Use division into two
		cases: n is even and n is odd.


		Suppose n is an integer.

		We must show that n² - n + 3 is odd using cases.

		Case 1: n is even

			Defintion of even:

			"n is even ↔ n = 2k, for some k ∈ ℤ"

			Let n, m, k ∈ ℤ

			n = 2m

			n² - n + 3 = (2m)² - (2m) + 3 =
			= 4m² - 2m + 3 =
			= 2(2m² - m + 1) + 1

			k = 2m² - m + 1

			n² - n + 3 = 2k + 1

			2k + 1 fulfills the definition of odd,
			for some k ∈ ℤ.

			Therefore, if n is even, then n² - n + 3
			is odd.


		Case 2: n is odd

			Definition of odd:

			"n is odd ↔ n = 2k + 1, for some k ∈ ℤ"

			Let n, m, k ∈ ℤ

			n = 2m + 1

			n² - n + 3 = (2m + 1)² - (2m + 1) + 3 =
			= 4m² + 4m + 1 - 2m - 1 + 3 =
			= 4m² + 2m + 3
			= 2(2m² + m + 1) + 1

			k = 2m² + m + 1

			n² - n + 3 = 2k + 1

			2k + 1 fulfills the definition of odd,
			for some k ∈ ℤ.

			Therefore, if n is odd, then n² - n + 3
			is odd.

Solution:	If n is even or n is odd, then n² - n + 3 is odd
