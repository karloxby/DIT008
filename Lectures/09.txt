THEOREM (5.2.2): GEOMETRIC SUM

(A) r in R, r ≠ 1 and (A) n in Z**≥0, (n)SUM(i=0) = r**i = r**n+1 - 1 / r - 1

Proof (by Induction):

Let r in R, r ≠ 1 and n in Z**≥0 Let P(n) be
(n)SUM(i=0) = r**i = r**n+1 - 1 / r -1

Base step:

	Establish P(0)

	LEFT:
	(0)SUM(i=0) r**i = r**0 = 1

	RIGHT:
	r**0+1 - 1 / r - 1 = 1

	Hence P(0) is true

Inductive case:

	Let k in Z**≥0 and assume P(k). Then,
	(k+1)SUM(i=0) r**i = (k)SUM(i=0) r**i + r**k+1

	P(k) = r**k+1 - 1 / r - 1 + r**k+1

	= r**k+1 - 1 + r**k+1(r-1) / r - 1 = r**k+2 - 1 / r - 1

	Hence P(k+1) is true.

						(Proof)

5.7	SOLVING RECURRENCE RELATIONS BY ITERATION

Finding an explicit expression for a recurrence
relation is called SOLVING the recurrence, e.g. for
the tower of Hanoi, m(subscript)n = 2**n -1


METHOD OF ITERATION

Calculate successive terms until a pattern
emerges and guess a general formula. This
guess can be verified by an induction proof.

A sequence a0, a1, ... is an ARITHMETIC SEQUENCE
iff there is a constant d in R st ak = ak-1 + d (A) k ≥ 1

Use method of iteration:

a0
a1 = a0 + d
a2 = a1 + d = a0 + d + d = a0 + 2d
a3 = a2 + d = a0 + 3d

Hence, guess that ak = a0 + kd (A) k ≥ 0

Proof by induction:

Base case: k = 0

	a0 + 0*d = 0

	so ak = a0 + kd for k = 0

Inductive step:

Suppose that ak = a0 + kd for some k ≥ 0. Then

	ak+1 = ak + d
	= a0 + kd + d = a0 + (k+1)d, as desired

					(Proof)

DEFINITION:

Let A, B be subsets of a universal set U.

A ∪ B = {x in U | x in A or x in B)		"union"

A - B = {x in U | x in A and x not in B}	"difference"

Aᶜ = {x in U | x not in A}			"complement"


DEFINITION:

PARTITIONS OF SETS

Sets can be divided into non-overlapping subsets. These
are called partitions.


DEFINITION:

Let A, B be sets. Then, A and B are DISJOINT
iff A ∩ B = ∅

E.g.

	{1, 2, 3} and {4, 5, 6} are disjoint.


DEFINITION:

Sets A₁, A₂, ... are MUTUALLY DISJOINT iff
Aᵢ ∩ Aⱼ = ∅ ∀i, j ∈ {1, 2, ...} with i ≠ j


DEFINITION:

A collection {A₁, Aₙ, ...} of sets is a partition
iff

	(1)	A is the union of all Aᵢ
	(2)	The Aᵢ are mutually disjoint


DEFINITION:

The POWER SET of a set A, 𝒫(A) is the set
of all subsets of A.

E.g. 𝒫({1, 2}) = {∅, {1}, {2}, {1, 2}}


1.2	ORDERED PAIRS AND CARTESIAN PRODUCTS


ORDERED PAIRS

Given a and b, "(a, b)" denotes an ORDERED PAIR.

	(a, b) = (c, d) means a = c and b = d

E.g.

	(1, 2) ≠ (2, 1) but {1, 2} = {2, 1}

Let n be an integer and x₁, x₂, ..., xₙ be elements

"(x₁, x₂, ..., xₙ)" is an ordered n-tuple

(x₁, x₂, ..., xₙ) = (y₁, y₂, ..., yₙ) 	iff 	x₁ = y₁
						x₂ = y₂
						...
						xₙ = yₙ

n = 2 	"ordered pair"
n = 3 	"ordered triple"


CARTESIAN PRODUCT

Given sets A₁, A₂, ..., Aₙ the CARTESIAN PRODUCT
A₁ × A₂ × ... × Aₙ is the set of all ordered n-tuples
(a₁, a₂, ..., aₙ) where aₙ ∈ Aₙ
