Proof: Look in book


Theorem 4.4.4
Any integer n > 1 is divisible by a prime number.

Proof:
	let n in Z, n > 1
	if n is prime, it is divisible by a prime

	if n is not prime, it is composite and hence
	(E) r0, s0 in Z+ s.t. n = r0s0 and 1 < r0 < n, 1 < s0 < n

	Hence, r0 | n. If r1 is prime, then we are done

	If r0 is composite (E) r1, s1 in Z s.t. r0 = r1s1 and 1 < r1 < r0, 1 < s1 < r0
	Hence, r2 | r1.

	Since r0 | n, r1 | n by theorem 4.4.3 if r1 is prime, then we are done
	If r1 is composite, we can keep factoring

	Since each factor is smaller than the previous one, and larger than 1,
	this terminates

	We end up with a sequence:
	r0, r1..., rk k in Z+ with
	1 < rk < rk-1 < ... < r0 < n					By theorem 4.4.1
	and ri | n for each i = 0, ..., k.

	We terminate at a prime, so rk is prime and rk | n
							(proof)

Unique factorization of integers:
In this proof above, we can continue factoring out primes from the ri and si,
by theorem 4.4.4:
	E.g.
		72 = 8 * 9 = 2 * 4 * 9 = 2 * 2 * 2 * 3 * 3
		     |   |   |   |   |   |   -----   -----
		     r0 s0   r1 s1  s0   r1    s1     s0

In fact, each integer can be uniquely written as a product
of primes.


Theorem 4.4.5 (FUNDAMENTAL THEOREM OF ARITHMATIC)

Given n in Z, n > 1, (E) k in Z, distinct primes p1, ..., pk in Z
and e1, ..., ek in Z+ st. 

n = p1**e1, p2**e2, ... pk**ek		= *

Any other expression for n as a product of primes is identical, up to order
* is called the STANDARD FACTORED FORM if the primes are in ascending order,
p1 < p2 < ... < pk

	E.g.
		The standard factored form of 72 is 2**3 * 3**2

		d = divisor
		q = quotient
		r = remainder

Definition:
Quotient and remainder can be computed using div and mod functions
	
	(A) n in Z, d in Z+, n div d = q, n mod d = r
			     <=> n = dq + r
	with q, r in Z and 0 ≤ r < d


Example 4.5.6:
	
	(A) n in Z, (E) q in Z st. n = 4q, n = 4q + 1, n = 4q + 2 or n = 4q + 3

	Proof:
		Let n in Z by thm 4.5.1 (QRT) with d = 4,

		We have (E) q, r in Z st. n = 4q + r and 0 ≤ r < 4

		The inequality implies that r is in {0, 1, 2, 3}
						(proof)


Division into cases:

To prove the statement "If A1 or A2 or ... or Ak, then C",
we show all of:

	If A1, then C
	If A2, then C
	If ..., then C
	If Ak, then C

Then, no matter which Ai is true, C is true.


Example
Thm 4.5.3

(A) n in Z odd, (E) m in Z st. n**2 = 8m + 1

Proof:
	Let n in Z be odd

	By Example 4.5.6 above, n can be written as either
	n = 4q, n = 4q + 1, n = 4q + 2 or n = 4q + 3 with
	q in Z
	
	Since n is odd and 4q and 4q + 2 is even,
	n must have one of the forms

		n = 4q + 1
		n = 4q + 3
	
	Case 1:
		n = 4q + 1 for some q in Z
		
		Then, n**2 = (4q + 1)**2 = 16q**2 + 8q + 1 = 8(2q**2 + q) + 1

		let m = 2q**2 + q. Then, m in Z and n**2 = 8m + 1

	Case 2:
		n = 4q + 3 for some q in Z

		Then, n**2 = (4q + 3)**2 = 16q**2 + 24q + 9 = 8(2q**2 + 3q + 1) + 1

		Let m ) 2q**2 + 3q + 1. then, m in Z and n**2 = 8m + 1
	
	Therefore, in both cases, (E) m in Z st. n**2 = 8m + 1
						(proof)
