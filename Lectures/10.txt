7.1	FUNCTIONS DEFINED ON GENERAL SETS

For X, Y sets, a FUNCTION 𝑓: X → Y is
a relation from the domain X to the co-
domain Y, such that 

	(1)	(A)x ∈ X, (E)y ∈ Y st (x, y) ∈ 𝑓
	(2)	If (x, y) ∈ 𝑓 and (x, z) ∈ 𝑓, then y = z

Hence, 𝑓 maps each x ∈ X to a unique element
𝑓(x) ∈ Y, the IMAGE OF X UNDER 𝑓.

7.2	ONE-TO-ONE, ONTO AND INVERSE FUNCTIONS

Functions can map two different elements of the
domain to the same element of the co-domain.

If this does not happen, the function is INJECTIVE.


DEFINITION

Let F : X → Y be a function. F is injective (one-to-one)
↔ ∀x₁, x₂ ∈ X : F(x₁) = F(x₂) → x₁ = x₂

Hence, F : X → Y is not injective ↔ ∃x₁, x₂ ∈ X st F(x₁) = F(x₂) and x₁ ≠ x₂

To prove injectivity, use a direct proof.

Suppose x₁, x₂ in X are such that F(x₁) = F(x₂)
Show that x₁ = x₂

i.e.
	To prove that a function is not injective, find x₁, x₂ ∈ X, such that
	F(x₁) = F(x₂) but x₁ ≠ x₂
