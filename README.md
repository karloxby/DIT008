## Definitions & Reference

### Even

n is even ↔ ∃k ∈ ℤ such that n = 2k

### Odd

n is odd ↔ ∃k ∈ ℤ such that n = 2k + 1

### Divisibility

d ∣ n ↔ ∃k ∈ ℤ such that n = dk

### Rational Number

r ∈ ℚ ↔ ∃a, b ∈ ℤ such that r = a/b and b ≠ 0

### Quotient-Remainder Theorem

∀n ∈ ℤ and ∀d ∈ ℤ⁺, ∃q, r ∈ ℤ such that

n = dq + r and 0 ≤ r < d

### Floor

⌊x⌋ = n ↔ n ≤ x < n + 1

### Ceiling

⌈x⌉ = n ↔ n - 1 < x ≤ n

### Mod

n mod d = r ↔ n = dq + r

where 0 ≤ r < d

### Set Difference

A ∖ B = {x ∈ A | x ∉ B}

### Subset

A ⊆ B ↔ ∀x (x ∈ A → x ∈ B)

### Set Equality

A = B ↔ A ⊆ B ∧ B ⊆ A

### Cartesian Product

A × B = {(a, b) | a ∈ A ∧ b ∈ B}

### Power Set

℘(A) = {B | B ⊆ A}
