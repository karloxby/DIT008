Parity

n even ⇔ ∃k ∈ ℤ such that n = 2k

n odd ⇔ ∃k ∈ ℤ such that n = 2k + 1

Prime and composite

A positive integer n is prime when n > 1 and its only positive divisors are 1 and n.

A positive integer greater than 1 is composite when it is not prime.

Existential proof

To prove ∃x ∈ D such that P(x), give one specific x in D for which P(x) is true.

Counterexamples

The negation of ∀x ∈ D, P(x) → Q(x) is ∃x ∈ D such that P(x) ∧ ¬Q(x).

A counterexample is one element for which the hypothesis is true and the conclusion is false.

Direct proof

Choose an arbitrary element satisfying the hypothesis. Use definitions and established facts to show that the conclusion follows. Because the element was arbitrary, the result holds universally.

Rational numbers

r ∈ ℚ ⇔ ∃a,b ∈ ℤ such that r = a/b and b ≠ 0

Every integer is rational because r = r/1.

Divisibility

d | n ⇔ ∃q ∈ ℤ such that n = qd, with d ≠ 0.

The expression d | n is a proposition. It is not a number.
